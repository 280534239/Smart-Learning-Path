## 处理结果摘要

### 内置内容与首次使用流程

- 移除内置 Python 知识图谱、示例题库和旧 Python 补充题库。
- 后端知识图谱与题库只加载用户生成内容，学习内容列表只返回当前用户可访问的生成内容。
- 新增首次学习内容创建页和登录后路由守卫；没有学习内容时不能进入学习空间。
- 新学习内容生成后进入初始诊断，完成诊断后才能进入学习页面。
- 删除最后一份学习内容后自动返回首次创建页。

### 学习目标优先级

- 学习目标标签支持 `1、2、3` 优先顺序和上下调整。
- 生成请求新增 `goal_priorities`，并兼容旧版 `goal` 字符串。
- 知识图谱生成提示词按优先级要求模型优先覆盖高优先级目标。
- 初始诊断后的个性化路径按目标优先级、掌握度、难度匹配和先修依赖综合排序。
- 初始诊断页、路径摘要和学习路径页展示目标优先级。

### 模型调用与控制台稳定性

- 定位到 `deepseek-v4-flash` 在 JSON 模式下可能只返回推理内容，正式答案为空。
- 默认模型切换为 `deepseek-chat`，并保留 `AI_MODEL_NAME` 环境变量配置能力。
- 内容生成和题目生成启用 JSON 输出模式，减少格式校验失败。
- 单次模型请求超时调整为 75 秒，连接超时调整为 10 秒，前端生成请求超时为 180 秒。
- 模型错误区分为超时、连接失败、限流、模型名称或 API Key 错误，并向前端返回具体原因。
- 不同知识点的题目改为并发生成，仅对题库写入串行加锁。
- 前端增加生成等待状态，避免失败时产生未处理 Promise 控制台错误。
- 端到端实测学习内容生成约 8 秒，控制台无异常或失败请求。

### 用户中心一期 MVP

- 新增 `/user-center` 页面和侧边栏入口，顶栏头像改为可点击菜单。
- 个人资料支持昵称、个人简介和头像上传替换。
- 学习档案跨学习内容汇总学习时长、做题数、正确率、连续学习天数、错题数、AI 会话数、内容掌握度、诊断历史和路径列表。
- 偏好设置支持亮色/暗色主题和默认学习内容。
- 账号安全支持修改密码和退出登录。
- 旧数据库启动时自动补充 `nickname`、`bio` 字段。
